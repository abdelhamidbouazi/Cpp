    <h1>C++ Projects Repository</h1>
    <p>This repository contains my solutions for the C++ programming projects from the 42 Network's C++ curriculum. The projects cover a wide range of topics and concepts, from basic data types and control structures to advanced object-oriented programming and algorithm design.</p>
    <h2>Projects</h2>
    <ul>
      <li><strong>CPP Module00:</strong> Introduction to C++ programming, basic data types, and control structures.</li>
      <li><strong>CPP Module01:</strong> Memory allocation, references, and pointers.</li>
      <li><strong>CPP Module02:</strong> Ad-hoc polymorphism, operator overload, and canonical classes.</li>
      <li><strong>CPP Module03:</strong> Inheritance and polymorphism.</li>
      <li><strong>CPP Module04:</strong> Subtype polymorphism, abstract classes, and interfaces.</li>
      <li><strong>CPP Module05:</strong> Repetitive inheritance, nested classes, and exceptions.</li>
      <li><strong>CPP Module06:</strong> Type casts, templates, and STL.</li>
      <li><strong>CPP Module07:</strong> Advanced topics such as smart pointers, lambda expressions, and move semantics.</li>
    </ul>
    <h2>Getting Started</h2>
    <p>To compile and run these projects, you will need to have a C++ compiler installed on your machine, such as GCC or Clang. You can compile the source code by running the following command in your terminal:</p>
    <code>g++ -Wall -Werror -Wextra -std=c++98 main.cpp</code>
    <p>You can then run the compiled executable by running the following command:</p>
    <code>./a.out</code>
